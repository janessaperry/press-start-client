# Press Start

## Overview

Press Start is a web app that helps users build and manage their collection of video games. It helps users keep track of
the games they own (and what system and format each game is).

## Features

- **User Authentication**: Secure sign-up and login functionality
- **Game Collection Management**: Track your owned games, including system and format
- **Game Exploration**: Discover new games to add to your collection

## Technologies Used

- **Frontend**: React, TypeScript, Vite
- **UI Components**: Headless UI
- **Routing**: React Router
- **HTTP Client**: Axios
- **Icons**: Phosphor Icons
